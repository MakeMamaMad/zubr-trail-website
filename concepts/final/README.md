# ZUBR TRAIL — директорская презентация GOLD / LIME

## Варианты
- [ZUBR GOLD](../01-forge/index.html): чёрный/золотой промышленный дизайн.
- [ZUBR LIME](../04-vector/index.html): светлая/графитовая технологичная версия с лаймовыми акцентами.
- [Сравнение](./index.html): две отдельные версии на одной странице.

Прямые адреса GitHub Pages:
- https://makemamamad.github.io/zubr-trail-website/concepts/01-forge/index.html
- https://makemamamad.github.io/zubr-trail-website/concepts/04-vector/index.html
- https://makemamamad.github.io/zubr-trail-website/concepts/final/index.html

## Функциональные страницы каждой концепции

1. `index.html` — самостоятельная главная.
2. `catalog.html` — все шесть моделей, фильтрация и сравнение.
3. `model.html?id=SAT-500` — характеристики конкретной модели. Поддерживаются SAT-150, SAT-197, SAT-500, SAT-510, SAT-545, SAT-550.
4. `technology.html` — переключаемые технологические блоки.
5. `production.html` — этапы изготовления и описания процессов.
6. `test-drive.html` — заявка с предвыбором модели.
7. `news.html` — материалы без вымышленных дат и новостей.
8. `article.html?slug=aluminum` — полноценная страница статьи.
9. `contacts.html` — телефон, адрес, почта, карта.

Дополнительно на LIME: конфигуратор с выбором шести моделей, переключением шагов, синхронизированными характеристиками и ссылкой на запрос.

## Изображения
- Исходные иллюстрации: `/assets/*.webp`.
- Оптимизированная GOLD-палитра: `/assets/colorways/gold/*.webp`.
- Оптимизированная LIME-палитра: `/assets/colorways/lime/*.webp`.
- Генератор: `concepts/build-colorways.py`, GitHub Actions `colorway-assets.yml`.

Изображения — концептуальные визуализации, не документальные фотографии серийных машин. Важно согласовать снимки реальных изделий перед коммерческим запуском.

## Функции и ограничения
- Полностью адаптивные страницы; Dark/Light с сохранением пользовательского выбора.
- Фильтры, сравнение моделей, технические вкладки, навигация, ссылки внутри каталога.
- GitHub Pages — статический хостинг. Заявка на тест-драйв формирует письмо в почтовом приложении, а не отправляется сайтом автоматически. Для коммерческого запуска подключить проверенный backend/форм-провайдер и документы по обработке персональных данных.
- Никакие фальшивые события, цены и сертификаты не публикуются.
- Технические значения зависят от комплектации; первичный источник для проверки — https://satpricep.by/.
- Прежнее название производителя в публичном контенте не используется.

## Контроль качества
`.github/workflows/concepts-qa.yml` проверяет страницы всех четырёх концепций в Chromium, мобильное меню, темизацию, каждую из шести модельных карточек, переходы к тест-драйву, статьи, сравнение и вкладки технологий. Результаты и скриншоты: `concepts/previews/`.

Основной `index.html` и исходный сайт ZUBR TRAIL не заменены — варианты опубликованы в подпапках.
