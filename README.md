# ZUBR TRAIL — официальный веб-проект (демоверсия)

**Слоган:** Современные полуприцепы для ваших задач.

**Дизайн:** ZUBR TRAIL с переключением Dark / Light.

## Адрес сайта

https://makemamamad.github.io/zubr-trail-website/

## Структура

- `/` — главная страница
- `/models/` — модельный ряд и фильтрация
- `/models/sat-150.html`, `sat-197.html`, `sat-500.html`, `sat-510.html`, `sat-545.html`, `sat-550.html` — отдельные страницы моделей
- `/technology/` — технологии и преимущества
- `/production/` — производство
- `/news/` — новости и технические материалы
- `/test-drive/` — запись на демонстрацию
- `/contacts/` — контакты

## Где находится код

- `site.css` — общие стили, адаптивность, две темы
- `site.js` — страницы, модельный ряд, навигация, фильтры и форма
- `assets/*.webp` — десять собственных иллюстраций техники и производства
- `.github/workflows/pages.yml` — автоматическая публикация из `main`

GitHub Pages публикует новую версию после изменений ветки `main`, когда Pages настроен на источник **GitHub Actions**.

## Что необходимо перед коммерческим запуском

1. Подтвердить технические характеристики каждого исполнения и заменить художественные визуализации на утверждённые материалы.
2. Согласовать рабочие контакты и почтовый домен ZUBR TRAIL.
3. Подключить серверную обработку заявок и юридически корректную политику обработки данных. Сейчас формы открывают готовое письмо в почтовом клиенте посетителя и **не отправляют данные на сервер**.
4. Утвердить реальные датированные новости. На странице новостей сейчас публикуются только инженерные материалы.
5. Провести финальные тесты на живом домене, проверить аналитику и SEO.

В публичных брендовых заголовках используется только название **ZUBR TRAIL**.
