# ZUBR TRAIL

Современные полуприцепы для ваших задач.

Это демонстрационная версия сайта ZUBR TRAIL, опубликованная с помощью GitHub Pages.

## Сайт

https://makemamamad.github.io/zubr-trail-website/

## Развёртывание

Изменения в ветке `main` автоматически запускают `.github/workflows/pages.yml`.

Прототип: переключение тёмной и светлой темы, каталог SAT-150, SAT-197, SAT-500, SAT-510, SAT-545, SAT-550, технологии и преимущества, новости и демонстрационная форма тест-драйва. Заявки пока не отправляются на сервер.
