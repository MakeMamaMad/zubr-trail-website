# ZUBR TRAIL — VECTOR

Отдельный многостраничный сайт в `/vector/`. Основная версия ZUBR POWER остаётся в корне репозитория и не изменяется.

Страницы: index.html, models.html, model.html?id=SAT-500, compare.html, solutions.html, technology.html, production.html, news.html, article.html?slug=moving-floor, request.html, test-drive.html, contacts.html.

Функции: фильтры и поиск каталога, сравнение до трёх моделей, выбор по типу груза, карточки моделей и публикаций, мобильная навигация, переключение светлой и тёмной темы, локальное запоминание выбора, формирование письма-запроса через mailto. Серверного обработчика заявок нет.

Изображения временно переиспользуются из `/assets/` и являются визуализациями. Не выдавать их за фото реальной техники. Точные параметры согласовать с производителем перед коммерческим запуском. Предварительные контакты подтвердить. Подготовить юридические документы о персональных данных. Форма требует подключить серверную отправку.

Для публикации используется существующий GitHub Pages workflow. Канонический адрес новой версии: https://makemamamad.github.io/zubr-trail-website/vector/
